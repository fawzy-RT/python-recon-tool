# Python Recon Tool

i made this tool to help me automate recon 
when i do penetration testing practice
it took long time to build and there will be more coming soon 😄

## what it does
- get ip and dns info
- find subdomains
- check http headers
- scan for directories
- find emails
- show geolocation
- generate google dorks

## requirements
apt install whois 
// pip install requests

## how to run
python3 recon.py example.com
python3 recon.py user@example.com
python3 recon.py 8.8.8.8

## note
only use this on targets you have permission to test
